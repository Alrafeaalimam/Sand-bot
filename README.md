# سند بوت — Sanad Bot

بوت واتساب للتوعية من مخاطر المخدرات في السودان، فيه وضعين:

- **الخبير المجهول**: أسئلة حرة تتجاوب عبر Groq API، مبنية على قاعدة معرفة (`data/knowledge.json`) ومقيّدة بـ system prompt صارم يمنع أي تفاصيل عن التعاطي أو التصنيع.
- **لعبة القرار**: سيناريوهات تفاعلية (`data/game.json`) بخيارات متعددة ونتائج مختلفة، تعمل كـ state machine بسيط.

## واجهة الويب (للعرض على الدكتور)

فيه واجهة شات على المتصفح بنفس منطق البوت بالظبط (القائمة، اللعبة، الخبير)، بلا حاجة لواتساب أو QR:

```bash
npm run web
```

بعدين افتح `http://localhost:3000` من المتصفح (أو من هاتفك لو مربوط بنفس الشبكة، عبر IP الجهاز).

## التشغيل في Termux (بوت الواتساب)

```bash
cd sanad-bot
npm install
cp .env.example .env
# حط الـ GROQ_API_KEY في .env
npm start
```

أول تشغيل، امسح كود الـ QR اللي يظهر في التيرمنال بواتساب (جهاز مرتبط).

## هيكل المشروع

```
sanad-bot/
├── data/
│   ├── knowledge.json   # قاعدة أسئلة وأجوبة التوعية
│   ├── game.json        # سيناريوهات لعبة القرار
│   └── users.json       # (يتولد تلقائياً) حالة كل مستخدم
├── src/
│   ├── store.js         # تخزين حالة المستخدم
│   ├── groq.js           # التكامل مع Groq API
│   ├── gameEngine.js     # منطق لعبة القرار
│   └── menu.js           # نصوص القوائم
├── index.js               # نقطة الدخول (Baileys)
└── package.json
```

## إضافة سيناريو جديد للعبة

أضف عقد جديدة في `data/game.json` تحت `nodes`، وأضف سيناريو جديد في `scenarios` يشاور على أول عقدة (`start`). كل عقدة فيها `text`، و`options` (كل خيار فيه `text` و`next`)، أو `ending: true` + `feedback` لو نهاية.

## إضافة سؤال جديد لقاعدة المعرفة

أضف كائن جديد في `data/knowledge.json` بنفس الشكل (`id`, `category`, `question`, `answer`). البوت بياخدها تلقائياً كمرجع في الـ system prompt.

## ملاحظات أمان

- تأكد الموديل في `.env` (`GROQ_MODEL`) نشط وموجود في [قائمة موديلات Groq](https://console.groq.com/docs/models) — الموديلات بتتغير بين فترة وأخرى.
- `users.json` بيحتوي أرقام واتساب المستخدمين — لا ترفعه لأي repo عام. أضفه في `.gitignore`.
- ممنوع تعديل الـ system prompt في `groq.js` بطريقة تفتح الباب لتفاصيل تعاطي أو تصنيع.
